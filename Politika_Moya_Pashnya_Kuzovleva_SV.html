Политика конфиденциальности

мобильного приложения «Моя Пашня»

Редакция № 1.0 Вступила в силу: 8 октября 2026 года

Настоящая Политика описывает порядок использования, хранения и обработки информации в приложении «Моя Пашня». Пожалуйста, ознакомьтесь с документом перед использованием приложения.

1. Общие положения

1.1. Настоящая Политика конфиденциальности определяет порядок использования, хранения и обработки информации в мобильном приложении «Моя Пашня» (далее — Приложение).

1.2. Разработчиком и лицом, предоставляющим Приложение, является Кузовлева С.В., физическое лицо, применяющее специальный налоговый режим «Налог на профессиональный доход» (самозанятая). Электронная почта: myplowedfield@internet.ru.

1.3. Приложение представляет собой программный инструмент для самостоятельного ведения учёта заказов, клиентов и выполненных работ по обработке земельных участков.

1.4. Приложение работает преимущественно в автономном режиме и не требует регистрации, авторизации или создания учётной записи.

1.5. Разработчик предоставляет пользователям программные инструменты для самостоятельного внесения, изменения, хранения и удаления информации.

1.6. Разработчик не осуществляет централизованное хранение баз заказов и клиентов пользователей.

2. Разграничение ответственности

2.1. Приложение является программным инструментом, позволяющим пользователю самостоятельно вести собственную базу заказов и клиентов.

2.2. Пользователь самостоятельно определяет: какие сведения вносить в Приложение; сведения о каких лицах сохранять; цели использования этих сведений; продолжительность их хранения; необходимость изменения или удаления записей; порядок создания и хранения резервных копий.

2.3. Разработчик не определяет содержание записей, создаваемых пользователем, и не осуществляет их проверку.

2.4. Пользователь самостоятельно отвечает за законность внесения и дальнейшего использования персональных данных третьих лиц, включая наличие необходимых правовых оснований для их обработки.

2.5. Разработчик не является лицом, которое по поручению пользователя получает и хранит его базу клиентов на удалённом сервере.

2.6. Разработчик не имеет технической возможности удалённо просматривать, изменять или удалять записи, находящиеся исключительно в локальном хранилище устройства пользователя.

2.7. При этом разработчик самостоятельно несёт предусмотренную законодательством ответственность за обработку данных, которую осуществляет непосредственно он или используемые им сервисы, в частности в связи с аналитикой Приложения.

2.8. Настоящий раздел не ограничивает права субъектов персональных данных и не освобождает стороны от обязанностей, установленных законодательством Российской Федерации.

3. Какие данные пользователь может сохранять

3.1. Пользователь может самостоятельно вносить в Приложение: имя клиента; номер телефона; город или населённый пункт; адрес земельного участка; дату выполнения заказа; площадь участка; стоимость работ; комментарии; оценку заказа; фотографию, связанную с заказом.

3.2. Указанные сведения используются для формирования локальной базы заказов и клиентов.

3.3. Разработчик не получает перечисленные сведения автоматически в собственную базу данных.

3.4. Приложение не требует предоставления паспортных данных или создания личного кабинета.

4. Локальное хранение информации

4.1. Основная информация о заказах и клиентах хранится непосредственно на устройстве пользователя.

4.2. Приложение не использует собственный удалённый сервер разработчика для хранения базы заказов и клиентов.

4.3. Каждый пользователь самостоятельно формирует собственную базу данных.

4.4. Базы данных разных пользователей не объединяются и не синхронизируются между устройствами через сервер разработчика.

4.5. Разработчик не располагает техническими средствами для получения доступа к локальной базе данных другого пользователя.

4.6. Разработчик не может определить, какие конкретно клиенты записаны в Приложении на устройстве определённого пользователя.

4.7. Разработчик не может самостоятельно изменить или удалить такие записи на чужом устройстве.

4.8. Исключением являются сведения, которые пользователь добровольно направляет разработчику, например при обращении в техническую поддержку.

5. Ответственность за внесённые данные

5.1. Пользователь самостоятельно принимает решение о внесении персональных данных клиентов в Приложение.

5.2. Пользователь обязан обеспечить законность обработки внесённых им персональных данных в соответствии с применимым законодательством.

5.3. Пользователь самостоятельно отвечает за достоверность и актуальность сохраняемых сведений.

5.4. Пользователь обязан принимать необходимые меры для предотвращения неправомерного доступа третьих лиц к сохранённой информации.

5.5. Пользователь не должен использовать Приложение для незаконного сбора, хранения или распространения персональных данных.

5.6. Если клиент требует удаления своих персональных данных из базы пользователя, лицо, которое внесло и использует соответствующие сведения, должно рассмотреть такое требование в соответствии с применимым законодательством.

5.7. Разработчик не осуществляет контроль за содержанием локальных баз пользователей и не может принудительно удалять отдельные записи с их устройств.

6. Фотографии

6.1. Приложение позволяет прикреплять фотографии к заказам.

6.2. Фотографии сохраняются в составе локальных данных Приложения.

6.3. Разработчик не получает фотографии заказов автоматически.

6.4. Пользователь самостоятельно отвечает за содержание добавляемых фотографий и наличие законных оснований для их хранения и использования.

6.5. Пользователь может удалить фотографию вместе с соответствующим заказом средствами Приложения.

7. Резервное копирование

7.1. Приложение предоставляет возможность создания резервной копии локальной базы данных.

7.2. Резервная копия может содержать информацию о клиентах, заказах, фотографии и другие сохранённые сведения.

7.3. Пользователь самостоятельно выбирает место сохранения резервной копии.

7.4. Разработчик не получает резервную копию автоматически.

7.5. Если пользователь самостоятельно отправляет резервную копию через электронную почту, мессенджер или облачный сервис, дальнейшая обработка файла зависит от выбранного способа передачи и условий соответствующего сервиса.

7.6. Пользователь самостоятельно отвечает за сохранность резервных копий и предотвращение несанкционированного доступа к ним.

7.7. Разработчик не имеет технической возможности удалять резервные копии, которые пользователь сохранил на собственных устройствах или в сторонних сервисах.

8. Аналитика AppMetrica

8.1. Для анализа работы Приложения разработчик использует сервис AppMetrica.

8.2. Сервис может обрабатывать технические и аналитические сведения, включая информацию об устройстве, операционную систему и её версию, версию Приложения, технические идентификаторы, сведения о запуске и использовании Приложения, информацию о событиях и технических ошибках, а также иные технические данные в соответствии с настройками SDK.

8.3. В AppMetrica могут передаваться события, связанные с использованием функций Приложения, например создание или удаление заказа, добавление фотографии, открытие статистики и создание резервной копии.

8.4. Разработчик не предусматривает передачу в составе специально настроенных аналитических событий имён клиентов, номеров телефонов, адресов, комментариев и фотографий заказов.

8.5. Технические и аналитические данные передаются сервису AppMetrica для получения статистики, анализа работоспособности и улучшения Приложения.

8.6. Обработка данных сервисом AppMetrica осуществляется с учётом условий и документации соответствующего сервиса.

8.7. Разработчик рассматривает обращения, касающиеся аналитических данных, в пределах имеющихся у него полномочий и технических возможностей.

9. Передача информации третьим лицам

9.1. Разработчик не продаёт базы клиентов и заказов пользователей.

9.2. Разработчик не предоставляет третьим лицам удалённый доступ к локальным базам пользователей.

9.3. Информация может передаваться за пределы устройства при работе аналитического сервиса AppMetrica — в отношении технических и аналитических данных; при самостоятельном экспорте и отправке резервной копии пользователем; при добровольном направлении пользователем информации разработчику; в иных случаях, предусмотренных законодательством.

9.4. Разработчик не осуществляет автоматическую передачу содержимого локальной базы заказов в собственное серверное хранилище.

10. Удаление данных

10.1. Пользователь самостоятельно управляет записями, сохранёнными на своём устройстве.

10.2. Удаление отдельных заказов осуществляется средствами Приложения.

10.3. Пользователь также может удалить локальные данные Приложения средствами операционной системы устройства.

10.4. При удалении Приложения локально сохранённая информация может быть утрачена.

10.5. Резервные копии, сохранённые отдельно, необходимо удалять самостоятельно.

10.6. Разработчик не имеет удалённого доступа к локальным данным пользователей и не может самостоятельно удалять их с чужих устройств.

10.7. Если субъект персональных данных обнаружил, что сведения о нём хранятся в Приложении на устройстве другого лица, он вправе обратиться к лицу, которое внесло и использует соответствующие сведения, с требованием об их удалении или прекращении обработки при наличии предусмотренных законом оснований.

10.8. При получении обращения на myplowedfield@internet.ru разработчик рассматривает его в пределах своей компетенции.

10.9. Если обращение касается исключительно локальной базы другого пользователя, разработчик разъясняет отсутствие технического доступа к такой базе и сообщает о возможности обращения к лицу, которое непосредственно хранит и использует соответствующие сведения.

10.10. Если обращение касается данных, которые обрабатываются самим разработчиком или используемыми им сервисами, разработчик рассматривает его и принимает необходимые меры в порядке, предусмотренном законодательством Российской Федерации.

11. Сроки хранения

11.1. Данные заказов и клиентов хранятся на устройстве пользователя до их удаления пользователем либо утраты локального хранилища.

11.2. Разработчик не устанавливает единый срок хранения записей, которые пользователь самостоятельно создаёт и использует в собственной локальной базе.

11.3. Пользователь обязан самостоятельно соблюдать применимые к нему требования законодательства относительно сроков хранения персональных данных.

11.4. Резервные копии сохраняются до их удаления пользователем или выбранным им сервисом хранения.

11.5. Сроки обработки аналитических данных определяются применимыми условиями AppMetrica, настройками сервиса и требованиями законодательства.

11.6. Информация, добровольно направленная разработчику при обращении, хранится не дольше, чем необходимо для рассмотрения обращения и выполнения установленных законом обязанностей.

12. Безопасность информации

12.1. Разработчик предоставляет программные средства для локального хранения и управления данными.

12.2. Пользователь самостоятельно обеспечивает физическую и программную безопасность своего устройства.

12.3. Рекомендуется использовать блокировку экрана и не предоставлять посторонним лицам доступ к устройству.

12.4. Пользователь должен обеспечивать безопасное хранение резервных копий.

12.5. Разработчик не может гарантировать сохранность данных при повреждении устройства, удалении Приложения, сбросе настроек телефона или действиях третьих лиц.

12.6. Разработчик принимает необходимые меры защиты в отношении информации, которую он непосредственно получает и обрабатывает.

13. Права субъектов персональных данных

13.1. Субъекты персональных данных обладают правами, предусмотренными законодательством Российской Федерации, включая право на получение информации об обработке своих данных и предъявление требований об их уточнении, блокировании или уничтожении в предусмотренных законом случаях.

13.2. Реализация соответствующих прав осуществляется с учётом того, какое лицо фактически обрабатывает данные и определяет цели их использования.

13.3. Если персональные данные хранятся исключительно в локальной базе другого пользователя, разработчик не располагает технической возможностью самостоятельно получить доступ к таким сведениям и удалить их.

13.4. В указанной ситуации субъект персональных данных может обратиться непосредственно к лицу, которое осуществляет их хранение и использование.

13.5. По вопросам обработки данных самим разработчиком можно обратиться по адресу: myplowedfield@internet.ru.

13.6. Разработчик рассматривает обращения и предоставляет ответы в соответствии с требованиями законодательства Российской Федерации.

13.7. Отсутствие технического доступа к локальным базам других пользователей не ограничивает установленные законом права субъектов персональных данных.

14. Обращения к разработчику

14.1. Пользователь может направить обращение по вопросам работы Приложения, конфиденциальности, аналитических данных, обработки информации разработчиком, удаления или уточнения сведений, находящихся под контролем разработчика.

14.2. Контактный адрес: myplowedfield@internet.ru.

14.3. Разработчик рассматривает обращения в пределах своей компетенции и предусмотренных законодательством обязанностей.

14.4. Разработчик не предоставляет услуги удалённого администрирования локальных баз пользователей.

14.5. Разработчик не располагает централизованным реестром клиентов, внесённых пользователями в Приложение.

15.1. Разработчик вправе изменять настоящую Политику при изменении функциональности Приложения, порядка обработки информации или требований законодательства.

15.2. Актуальная редакция Политики размещается внутри Приложения и по публичной ссылке, указанной в карточке Приложения в RuStore.

16. Заключительные положения

16.1. Приложение «Моя Пашня» предназначено для самостоятельного ведения учёта заказов и клиентов.

16.2. Разработчик предоставляет программный инструмент, но не осуществляет централизованное хранение созданных пользователями баз заказов.

16.3. Пользователь самостоятельно определяет содержание локальной базы и отвечает за законность обработки внесённых им персональных данных.

16.4. Разработчик не имеет удалённого доступа к локальным базам пользователей.

16.5. Настоящая Политика не освобождает разработчика от обязанностей в отношении персональных данных, которые он непосредственно обрабатывает.

16.6. Вопросы, не урегулированные настоящей Политикой, разрешаются в соответствии с законодательством Российской Федерации.
